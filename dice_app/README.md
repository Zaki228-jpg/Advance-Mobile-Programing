# Roll Dice Flutter Project

A simple Flutter game with two dice.

## Features
- Tap the left dice to roll only the left dice.
- Tap the right dice to roll only the right dice.
- Press ROLL BOTH to roll both dice.
- Shows the total of both dice.

## Run

1. Open this folder in VS Code.
2. Run:

```bash
flutter pub get
flutter run
```
